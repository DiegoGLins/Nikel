# Nikel

Esta é uma aplicação de gerenciamento de finanças realizado através do curso Codaí pela Growdev

This is a financial management application developed through the Codaí course by Growdev.

## Como rodar o projeto

Este projeto é uma aplicação web simples desenvolvida com HTML, CSS, JavaScript e Bootstrap. Não é necessário instalar dependências ou configurar um servidor.

Para executar:

1. Baixe ou clone este repositório.
2. Acesse a pasta do projeto.
3. Abra o arquivo `public/index.html` diretamente no navegador.

A partir da tela inicial, é possível criar uma conta, fazer login e utilizar as funcionalidades de controle financeiro. Os dados são armazenados localmente no navegador por meio de `localStorage` e `sessionStorage`.
